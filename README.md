### 🚀 About Me & Engineering Focus

I am a B.Tech Artificial Intelligence & Machine Learning undergraduate at **Symbiosis Institute of Technology (SIT), Pune**, specializing in high-throughput backend systems, autonomous agent architectures, and computer vision.

My engineering philosophy centers on **software honesty, rigorous testing, and verifiable execution**. I focus on:
- ⚡ **Low-Latency Systems & Concurrency**: Designing non-blocking async runtimes with Python (`asyncio`), FastAPI, WebSockets, and deterministic priority queues.
- 🤖 **Autonomous AI & Protocols**: Engineering Model Context Protocol (FastMCP) servers, 3-tier intelligent routing (deterministic regex bypass → local quantized SLMs → cloud reasoning models), and persistent SQLite memory graphs.
- 👁️ **Computer Vision & Edge ML**: Building diagnostic vision pipelines (crop pathology classification, intelligent traffic corridors) using PyTorch, OpenCV, and transfer learning.
- 🧪 **Engineering Rigor**: Practicing test-driven development (`pytest`), cryptographic audit trails (Merkle trees), and reproducible CI/CD pipelines.
